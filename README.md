# usd-museum

The USD Museum as real assets: wings, galleries and exhibits laid out the way a production
asset library would be. Each exhibit also carries its forgeries as small override layers.
[RULES.md](RULES.md) describes the layout.

Everything here is generated by [usd-tour](../usd-tour) (`museum/src/export.py`). Rebuild a
wing instead of editing it:

```sh
cd ~/git/usd-tour
kit/py museum/src/export.py composition       # writes ~/git/usd-museum/composition/, then checks it
```

## Wings

| Wing | Galleries | Exhibits | Forgeries |
|---|---|---|---|
| [composition](composition/composition.usda) | arcs, loading, strength, namespace, edits, errors | 9 | 97 |

The other nine wings are still only in usd-tour.

## Viewing

The whole wing on its tour, through usd-tour's usdview kit (load schedule, Tour menu):

```sh
~/git/usd-tour/view.sh ~/git/usd-museum/composition/tour.usda \
    --unloaded --camera /composition/tour/tour_cam --complexity high
```

Plain usdview works too, on anything:

```sh
usdview composition/composition.usda                          # the wing, every exhibit loaded
usdview composition/arcs/arcs/arcs.usda                       # one exhibit
usdview composition/arcs/arcs/forgeries/noinherit.usda        # the same exhibit with one planted mistake
```
