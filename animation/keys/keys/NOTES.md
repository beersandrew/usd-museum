# animation.keys.keys

Rebuilt in wave 1 (Nov 8) as three small stands, one hold each: time samples, the strongest layer, and types.
- Carts pitch along their tracks under a gantry playhead.
- Everything is transform-only, for OpenExec.
- The Types stand uses mesh topology, points and a skeleton, not PointInstancers.

See `museum/wings/animation/NOTES.md` and `src/build.py`. Test 3's single-bleacher version is in git history (commit 5416173).
